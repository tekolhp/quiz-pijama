# pixelfx (vendored)

`lib/` is a copy of `src/core` and a few effects from https://github.com/patch-gg/pixelfx (MIT, see `lib/LICENSE`
and `lib/NOTICE.md`). Only the effects the quiz uses are copied. `bridge.js` exposes them to `scene.js` as `window.PFX`.

Effects used: explosions/cartoon-pow, impacts/impact-frame, impacts/heavy-landing, ui/confetti, ui/combo-counter, pickups/collect-burst,
water/water-jet, weather/god-rays, critters/fish-school.
